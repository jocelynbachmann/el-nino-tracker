# Client (React + Vite + MapLibre)

The El Niño Tracker map. Needs **Node.js 22** or newer and **pnpm**, and the Flask server
running on port 5001 (see the main README).

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # production build in dist/
```

Requests to `/ocean/...` are proxied to `http://localhost:5001` (see `vite.config.js`); set
`VITE_OCEAN_API` to point at a different server.

- `src/App.jsx`: layout, date and layer state, predictions switch
- `src/components/`: map (`WestCoastMap.jsx`), history strip (`EventTimeline.jsx`), event card and list, help popovers
- `src/hooks/`, `src/lib/`: data loading from the server, colour maps, map images
- `public/herring-spawn.geojson`: generated by `pipeline/herring/fishies_geojson.py`
